\# REFLECTION MID-TERM



Selama Minggu 1 sampai Minggu 7, materi yang paling sulit saya pahami adalah Branching, Merging, dan penyelesaian Merge Conflict pada Git. Awalnya saya sering mengalami kebingungan saat berpindah branch dan melakukan merge karena muncul conflict pada file yang sama.



Saya mengatasi kesulitan tersebut dengan melakukan latihan berulang menggunakan Git di terminal, mencoba simulasi conflict, dan memahami fungsi setiap perintah Git secara bertahap. Selain itu, saya juga mulai memahami pentingnya struktur proyek seperti MVC agar pekerjaan Frontend dan Backend tidak saling bertabrakan.



Dari proses pembelajaran ini, saya memahami bahwa Software Development bukan hanya tentang menulis kode, tetapi juga tentang kolaborasi tim, dokumentasi, dan manajemen perubahan menggunakan Git dan GitHub.
